# Ridgewell Landscape & Design Website

## Overview

This project is a modern, high-performance lead-generation website built for Ridgewell Landscape & Design. The primary goal of the website is to showcase the company's landscaping and hardscaping services while maximizing customer inquiries through strategically placed calls-to-action, intuitive navigation, and a seamless user experience.

The website has been designed with a strong focus on conversion optimization, responsiveness, accessibility, performance, and modern UI/UX principles. Every section is carefully crafted to help potential customers understand the company's services, build trust, and ultimately request a consultation or estimate.
